# 🧪 UVM-Based AXI4 Verification Framework

### Design and Implementation of a UVM-Based AXI4 Verification Framework for High-Speed SoC and Memory Data Transfer Systems

A UVM-based verification environment developed for an **AXI4 Slave Memory DUT**.

### Verification Architecture

```text
                    UVM TEST
                       │
                       ▼
                    SEQUENCE
                       │
                       ▼
                AXI4 TRANSACTION
                       │
                       ▼
                    DRIVER
                       │
                       ▼
                  AXI4 DUT
                       │
             ┌─────────┴─────────┐
             ▼                   ▼
          MONITOR            DUT RESPONSE
             │                   │
             └─────────┬─────────┘
                       ▼
                   SCOREBOARD
                       │
                       ▼
                EXPECTED vs ACTUAL
                       │
                       ▼
                  PASS / FAIL
```

### Key Concepts

* UVM Architecture
* AXI4 Protocol
* Transaction Generation
* Driver & Monitor
* Scoreboard
* Functional Coverage
* Read/Write Transactions
* Burst Transactions
* Interface Handshaking
* Protocol Timing Analysis

**Simulation Tool:** Cadence Xcelium
